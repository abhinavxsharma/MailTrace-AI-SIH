# MAILTRACE AI

AI-Powered Email Threat Detection & Forensic Intelligence Platform.

## Workflow

Detect → Verify → Trace → Correlate → Explain → Report

## Project Structure

- `backend/` — FastAPI backend and API
- `ml/` — ML inference and model integration
- `forensics/` — Email parsing and forensic evidence
- `intelligence/` — DNS, RDAP, GeoIP and reputation enrichment
- `graph/` — Correlation, campaign and timeline analysis
- `frontend/` — React frontend
- `explainability/` — Explanation services
- `reports/` — Report generation
- `scripts/` — Utility scripts
- `docs/` — Project documentation
- `data/` — Sample/local development data
